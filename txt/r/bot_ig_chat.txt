================================================================================
 INSTAGRAM BOT PARAMETER SPECIFICATION : bot_ig_chat.py
================================================================================
 Nama Bot    : Bot Direct Message / Chat Instagram
 File Name   : bot_ig_chat.py
 Deskripsi   : Mengirimkan pesan singkat (DM) ke akun Instagram target.
 API Server  : /api/jalankan-bot-chat
--------------------------------------------------------------------------------

 [CLI RUNNING COMMAND SYNTAX]
   python3 bot_ig_chat.py <target_user> <pesan> [device_id]

 [DAFTAR PARAMETER COMMAND]
   * Posisi 1 : <target_user> (String) [WAJIB]
     Deskripsi : Username Instagram penerima pesan

   * Posisi 2 : <pesan> (String) [WAJIB]
     Deskripsi : Teks pesan yang ingin dikirim

   * Posisi 3 : <device_id> (String) [OPSIONAL] | Default: 'all'
     Deskripsi : ID Perangkat Android ADB

 [CONTOH PERINTAH RUNNING]
   $ python3 bot_ig_chat.py "halo_target" "Halo, salam kenal!" R9RY801LRPW
